BIP-322 PSBT Builder

Construct an unsigned BIP-322 PSBT for a hardware wallet to sign. Runs entirely in your browser — no keys leave this page, nothing is sent to a server.

Single-sig: pkh(...), wpkh(...), sh(wpkh(...)), tr(...). Multisig: sh(multi(...)), wsh(multi(...)), sh(wsh(multi(...))) — and sortedmulti equivalents (BIP-67). Taproot multisig is not supported. Each key must include origin info and a concrete child index — no /* wildcards. Optional #checksum suffix is accepted (not validated).
