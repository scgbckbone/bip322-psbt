BIP‑322 PSBT Creator

BIP-322 generalizes Bitcoin's message-signing standard so any script type — segwit, taproot, multisig — can sign an arbitrary message, not just legacy 1-addresses. The signed message is wrapped in a pair of virtual transactions, so any hardware wallet that can sign a transaction can also sign a message.

This page is the PSBT‑creator half of that flow: paste an output descriptor and a message; out comes the unsigned PSBT. Sign it with your hardware wallet, and the signature is a portable proof that you control the address — for proof of reserves, exchange attestations, or any "I'm the owner of this address" claim. Single-sig (pkh, wpkh, sh-wpkh, tr) and non-taproot multisig supported.

Single-sig: pkh(...), wpkh(...), sh(wpkh(...)), tr(...). Multisig: sh(multi(...)), wsh(multi(...)), sh(wsh(multi(...))) — and sortedmulti equivalents (BIP-67). Taproot multisig is not supported. Origin info [fp/path] is optional — when omitted the fingerprint is computed as hash160(pubkey)[:4] per BIP-32. Child paths after the xpub must be concrete (no /* wildcards). Optional #checksum suffix is accepted (not validated).
